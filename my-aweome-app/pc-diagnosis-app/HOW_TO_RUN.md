# 如何运行PC急救助手应用

PC急救助手是一个基于Web的应用，可以在任何现代浏览器中运行，无需安装额外的服务器软件。

## 运行方法

### 方法一：直接打开HTML文件（推荐）
1. 打开文件资源管理器
2. 导航到 `C:\Users\lwp\Desktop\pc-diagnosis-app` 目录
3. 双击 `index.html` 文件
4. 应用将在默认浏览器中打开

### 方法二：右键菜单打开
1. 在文件资源管理器中找到 `index.html` 文件
2. 右键点击文件
3. 选择"打开方式" → 选择您的浏览器（Chrome、Firefox、Edge等）

### 方法三：浏览器中打开
1. 打开您的浏览器
2. 在地址栏中输入以下路径：
   ```
   file://C:/Users/lwp/Desktop/pc-diagnosis-app/index.html
   ```
3. 按回车键

## 功能验证

为了确保应用正常工作，您可以执行以下验证步骤：

1. **文件完整性检查**：
   - 确保以下文件存在于目录中：
     - index.html（主页面）
     - styles.css（样式文件）
     - app.js（应用逻辑）
     - decision-tree.json（诊断数据）

2. **功能测试**：
   - 页面应正常加载，显示"PC急救助手"标题
   - 点击不同的故障选项应能正常跳转
   - 诊断流程应能正常进行
   - 结果页面应能正确显示

## 常见问题解决

### 1. 页面无法打开
- 确保使用现代浏览器（Chrome、Firefox、Edge）
- 检查文件路径是否正确
- 确保所有必需文件都存在

### 2. 功能不正常
- 检查浏览器控制台是否有错误信息（按F12打开开发者工具）
- 确保JavaScript已启用
- 刷新页面尝试重新加载

### 3. 样式显示异常
- 确保styles.css文件存在且可访问
- 清除浏览器缓存后重新加载

## 移动设备使用

要在手机上使用此应用：

1. **打包成APK**：
   - 参考APK_PACKAGING.md文件中的说明
   - 使用在线工具如PWABuilder生成APK文件

2. **通过浏览器访问**：
   - 将应用部署到Web服务器
   - 在手机浏览器中访问应用URL

## 应用功能说明

应用包含以下主要功能：

1. **多种故障类型诊断**：
   - 不开机、不通电
   - 蓝屏（BSOD）
   - 运行卡顿、反应慢
   - 无法上网
   - 没有声音
   - 电脑过热、噪音大
   - 其他问题

2. **引导式诊断流程**：
   - 多步骤问题排查
   - 实时进度显示
   - 针对性建议

3. **结果展示**：
   - 故障可能性排序
   - 详细的解决建议
   - 送修时的专业表述建议

通过以上方法，您就可以成功运行PC急救助手应用了。
